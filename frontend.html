Pattern Structure

«abstract» NotificationFactory Creator ├── + createNotification() : Notification ← factory method (abstract) └── + notify(recipient, msg) : String ← uses factory method internally │ ├── EmailNotificationFactory ConcreteCreator │ └── createNotification() → new EmailNotification() │ ├── SmsNotificationFactory ConcreteCreator │ └── createNotification() → new SmsNotification() │ └── PushNotificationFactory ConcreteCreator └── createNotification() → new PushNotification() «interface» Notification Product ├── EmailNotification implements Notification ├── SmsNotification implements Notification └── PushNotification implements Notification NotificationController → NotificationFactoryRegistry → NotificationFactory.notify() Controller never calls `new EmailNotification()` — the factory handles instantiation.
